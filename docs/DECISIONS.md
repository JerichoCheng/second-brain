# 技术决策记录

记录做过的关键决定和原因。推翻某条决定时不要删除，追加一条新记录说明为什么改。

---

### 04· 基于 DeepSeek Harness 调用 API，不本地部署模型
2026-10-03

省去本地推理的硬件和维护成本。代价是检索到的笔记和邮件内容会发送给 DeepSeek。

### 05· 只沿用 Ultimate Brain 的结构，不迁移 Notion 中的内容
2026-10-03

知识库从空开始。保留模板的数据库、字段、视图和工作流（GTD、My Day、My Week），用 schema 文件重新定义。

### 06· 数据存储为 Markdown + YAML frontmatter
2026-10-03

可以用任何编辑器打开、用 git 管理、agent 直接读取，不被任何软件锁定。数据库视图需要的查询能力由内存索引提供。

### 07· 不使用 SQLite，用内存索引
2026-10-03

个人知识库规模下（万级文件以内）内存索引足够快，且没有 Electron 原生模块的编译问题。如果将来性能不够再引入。

### 08· schema 驱动的界面
2026-10-03

所有数据库共用一套视图引擎。新增模块只需写 schema 文件，这让「保留所有模块」在工作量上可行。

### 09· 桌面框架选 Electron 而不是 Tauri
2026-10-03

Harness 是 Node.js，插件用 TypeScript；Electron 主进程本身就是 Node，整个应用只有一种语言。Tauri 需要额外打包 Node 运行时作为子进程，对个人项目是不必要的复杂度。代价是安装包更大。

### 10· AI 只能往 Inbox 写提案
2026-10-03

防止模型出错时悄悄改坏正式笔记。由 Harness 的 pre-execute 钩子强制执行，不依赖提示词。

### 11· 邮件采用固定流水线，而非 agent 自由读取
2026-10-03

抓取 → 本地规则过滤 → 模型分析 → 写入，流程可控、成本可预测。所有邮箱只读访问。

### 12· 邮件完整正文发送给 DeepSeek
2026-10-03

分析准确度优先。发件人规则命中的推广、通知类邮件不发送。

### 13· Agent 放在最后一个功能阶段
2026-10-03

前面的功能不依赖 agent 也完全可用；Harness 仍在开发者预览期，越晚接入接口越稳定。

### 14· 代码仓库与 vault 分离
2026-10-03

本仓库只放代码。vault 包含个人数据（联系人、邮件摘要等），单独存放并用私有仓库备份。

## 15. 构建工具用 electron-vite 5 + Vite 7

electron-vite 5 目前只支持到 Vite 7，所以没有用最新的 Vite 8。等 electron-vite 支持后再一起升级。

## 16. IPC 只暴露一个带白名单的 `invoke`

预加载脚本只暴露 `window.brain.invoke(channel, ...args)`，通道、参数和返回值类型都定义在 `shared/ipc.ts` 的 `IpcContract` 里。
主进程把结果包成 `{ ok, data } | { ok, error }` 返回，界面的 `lib/api.ts` 再还原成 `BrainError`。
原因：直接抛出的错误跨 contextBridge 后会丢失 `code` 等自定义字段；集中定义也让新增通道时漏写主进程一端会直接类型报错。

## 17. 只有空文件夹才自动做第一次 git 提交

在非空文件夹里初始化知识库时只执行 `git init`，不提交，避免把原有的文件一起提交进去。

### 18· 数据层独立成 packages/vault-core
2026-10-03

不依赖 Electron，主进程、阶段 6 的 vault 插件和测试共用同一套代码。界面通过主进程间接调用，不直接引用。

### 19· 条目属于哪个数据库由文件夹决定
2026-10-03

不再用 frontmatter 的 `type` 字段标识数据库，避免和笔记的子类型冲突。笔记、领域的子类型字段统一叫 `kind`。子文件夹归属最长匹配的数据库（如 `tasks/archive/` 仍是任务）。

### 20· YAML 用 `yaml` 库的 Document API，按 YAML 1.2 解析
2026-10-03

改一个字段时保留其他键的顺序、注释和格式，文件在 git 里的 diff 只有真正改动的那一行。1.2 的 core schema 不会把 `2026-10-17` 转成带时区的 Date 对象（gray-matter / js-yaml 会，在珀斯时区容易差一天）。

### 21· 页面名不区分大小写
2026-10-03

Windows 文件系统不区分大小写，`[[cits2002]]` 和 `[[CITS2002]]` 必须指向同一个文件，否则在 Windows 上会出现两个链接指向同一文件、却被当成两个页面的情况。

### 22· 删除改为移到 .brain/trash/
2026-10-03

界面和 agent 审批都可能误删，先保留一份。永久清理以后在设置页做。

### 23· 过滤条件支持「或」和 $this
2026-10-03

Ultimate Brain 的 Today 视图是「勾了 My Day 或今天及以前到期」，只有「与」写不出来，所以加了 `{ any: [...] }`。`$this` 给阶段 3 的页面内嵌视图用。
